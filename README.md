## 🌱 About the Project

**PashuMitra** is a livestock management web application designed to help farmers organize their animal records, track daily expenses and income, and understand their livestock-related financial performance in one place.

The goal is to make livestock record-keeping simpler, more accessible, and easier to manage.

## ✨ Features

- 🔐 **Farmer Accounts** — Registration and login.
- 🐄 **Animal Management** — Register animals and manage their details.
- 🌾 **Expense Tracking** — Record cattle feed, grass, and medical expenses.
- 🥛 **Milk Records** — Track morning and evening milk production.
- 💰 **Income Tracking** — Record income from livestock.
- 📊 **Profit & Loss Summary** — Review financial summaries.
- 📅 **Daily Records** — Save and review animal-wise daily history.

## 🚀 Run Locally

### Prerequisites

- Python installed on your computer
- Git installed
- A copy of this repository

### 1. Clone the repository

```bash
git clone https://github.com/Raviraj301006/PashuMitra.git
cd PashuMitra
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

Install the Python packages required by the project. If a `requirements.txt` file is available, run:

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
python app.py
```

Open the local address displayed in your terminal in your browser.

> Note: The project needs its required Python packages and database initialization before it can run on a new computer. Do not upload private database files or credentials.
